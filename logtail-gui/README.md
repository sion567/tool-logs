# logtail-gui — BareTail 风格的图形界面日志查看器

给不习惯终端 TUI 的同事做的 Windows 图形界面版日志实时监控（egui/eframe，单 exe，拷走即用）。
复用 [logtail-core](../logtail-core) 库的本地 tail 泵（含轮转自愈）、行解析/级别识别、过滤匹配、SSH 连接——两套界面共享同一套核心逻辑。

## 快速开始

```
logtail-gui.exe                      # 空窗口，按钮/拖拽打开文件
logtail-gui.exe app.log err.log     # 启动即开两个 tab
```

- **打开文件**：菜单「文件 → ＋ 打开文件…」、把 `.log` 拖进窗口、或命令行参数
- **连接远程源**：菜单「文件 → ⛓ 连接源…」列出 `~/.config/logtail/config.toml` 里的 `[[sources]]`
  （SSH 上的 docker / file / journalctl 源，与 TUI 完全同源同认证，TOFU 主机密钥校验自动生效）

## 功能（对齐 BareTail + TUI）

| 功能 | 说明 |
|---|---|
| 菜单栏 | 「文件」（打开/连接源/导出/清屏/重连/关闭 tab/退出）、「查看」（日志级别、倒序/分屏/折叠/时间轴/置顶）、「设置」（字号、行数上限有界档位、启动恢复开关、管理服务器与源、编辑 config.toml、打开配置目录）；低频操作全部收进菜单，窗口窄不换行。正则/过滤留在操作行 |
| 多文件 tab | 单按钮标签：`状态符 + 源名 + ×` 一体（点主体激活、点 × 关闭，激活浅蓝底）；状态符号 ●流中 ⋛连接中 ■已结束 ✗失败；标签区尾部显示激活源详情（本地=完整路径+大小，远程=user@host:port+源名）；`,` / `.` 或 Ctrl(+Shift)+Tab 键盘切换 |
| 实时 tail | 打开时回放末尾约 64KB，之后 300ms 轮询增量；文件轮转（copytruncate/改名重建）自动续读 |
| 跟随/暂停 | 默认跟随尾部；手动上滚自动暂停，滚回底部或点「↓ 末尾」恢复（BareTail 同款行为）。**手动取消勾选不会被自动恢复**——取消后就停在原地，重新勾选或点「↓ 末尾」恢复 |
| 倒序显示 | 「查看 → 倒序」开关（v0.10.8，默认关）：开 = **最新在顶**，跟随=钉住顶部、新行把旧行往下推；暂停时视口钉住（正在看的内容不被顶走），滚回顶部或点「↑ 最新」恢复。↑↓ 方向随视觉翻转（Down 恒为视觉向下）；导出仍为时间正序 |
| 分屏 | 「查看 → 分屏」（v0.10.10，≥2 个 tab 可用）：激活 tab 与下一个 tab 并排显示，**两栏独立**滚动/选中/跟随/右键（各有栏头标注跟随态）；工具栏过滤、详情条、键盘导航仍作用于激活 tab。记忆到 gui.toml |
| 过滤 | 文本（`|` 分隔多关键词任一命中）或正则（勾选）；命中行整行黄底；随输入实时生效 |
| 级别过滤 | 自动识别 ERROR/WARN/INFO/DEBUG 并着色；「查看 → 日志级别」按阈值过滤（ERROR+ = 仅 ERROR），作用于激活 tab |
| 模式/加载更早 | 远程 tab 专属：模式下拉（全量 / 快捷1h / 快捷24h / 精准近1h，改动即重连）+「⏮ 更早」（快捷时长翻倍、精准窗口前移，同 TUI `L` 键） |
| 远端预过滤 | 「远筛」（同 TUI `P` 键）：把过滤框关键词推到远端 `| grep -E`，服务器只回传匹配行；过滤框为空时按钮禁用（悬停有提示）；非法 pattern 拒绝且不拼接进命令 |
| 预设 | 「连接源」对话框底部预设区一键应用（level 本地立即生效；since 改模式重连），与 TUI 侧栏预设同源 config.toml `[presets]` |
| 相似行折叠 | 「查看 → 折叠」（默认开）：**相邻且消息体相同**（剥时间戳后）的行合并为一行，行尾 ` ×N`，刷屏场景一眼看到节奏；日志行内容各不相同时看不到变化属正常语义 |
| 日志量时间轴 | 「查看 → 时间轴」（默认开）：日志区上方细条按秒画日志量密度；**点击/拖动可定位到对应时间**（悬停显示时间、自动暂停跟随，点「↓ 末尾」恢复） |
| 选择与复制 | 单击选行；**Shift+单击扩成区间**，Ctrl+C 复制（区间 = 多行 `\n` 拼接）；右键菜单：**查看完整行** / 复制该行 / 复制选中 N 行 / 复制时间戳 / 复制 trace_id / **按 trace_id 过滤** |
| 行详情条 | **Enter**（选中后）/ **双击行** 或右键「查看完整行」打开：时间/级别/源/trace_id + 长行**自动折行显示全文**（底部条，复制该行/**复制上下文±5**/关闭）。详情打开时 **↑↓ 移动选中、详情跟随**（自动滚进视口），Esc/Enter 关闭。主视图固定单行（截断），`←→` 横滚、`Home` 复位，超长内容看详情条 |
| 清屏/导出 | 菜单「文件 → 清屏 / 导出…」：清屏重置缓冲；导出当前 tab 整份缓冲到所选目录（`logtail-<名>-<时间>.log`） |
| 显示设置 | 「设置」菜单：字号 A−/A+、行数上限（1000~50000 有界档位，对所有已开 tab 即时生效）、折叠/倒序/时间轴/置顶；重启后自动恢复（gui.toml），**上次的 tab 也自动恢复**（受 config `remember_last_source` 门控） |
| 编辑配置 | 「设置 → 管理服务器与源…」：窗口内增删改 config.toml 的**服务器**（host/端口/用户/认证：明文密码·密钥文件·**密钥环**/sudo）、**日志源**（docker/远程文件/journalctl/命令/Loki/本地）与**预设**（键/名称/级别/since），每次保存自动备份 `config.toml.bak` 且**保留手写注释**；「连接源」对话框内也有入口。「设置 → 启动恢复上次激活源」开关直写 `[general].remember_last_source`；进阶字段仍可「编辑 config.toml…」手改 |
| 远程重连 | 远程 tab 会话结束/失败后按「↻ 重连」（操作行会在此时自动出现，菜单里也有）重开（保留该 tab 的模式与远筛设置）；docker 权限拒绝时状态栏自动提示修复命令 |

## 配置

`~/.config/logtail/gui.toml`（首次运行后自动生成）：

```toml
font_size = 14.0          # 日志字号
max_lines = 10000         # 每个 tab 的行数上限（超出淘汰最旧；设置菜单 1000~50000 档位）
always_on_top = false     # 窗口置顶
recent_files = [...]      # 最近打开（打开新文件自动维护）
dedupe = true             # 相似行折叠 ×N
reverse = false           # 倒序显示（v0.10.8；true = 最新在顶）
split = false             # 分屏并排显示（v0.10.10；≥2 个 tab 生效）
show_sparkline = true     # 日志量时间轴细条
last_tab = { type = "local", path = "C:/logs/app.log" }   # 上次激活 tab，启动自动恢复
[window]                  # 窗口尺寸，退出时更新
w = 1280.0
h = 800.0
maximized = false
```

远程源配置与 TUI 共用 `~/.config/logtail/config.toml`（servers + sources + presets，写法见该文件的自动生成模板；TUI 文档 §8）。
远程 tab 的模式/远筛是会话内设置，不持久化（与 TUI 精准窗口不持久化同理）；下次启动该源以全量模式连接。

> **行数上限怎么选**：缓冲是内存窗口（不做长期存储），瘦身后每行约 250~300B——
> 默认 1 万行约 3MB/tab，5 万行约 15MB/tab，一般场景 1 万已绰绰有余；
> 设置菜单只给有界档位，不给任意值。gui.toml 由应用自动落盘，**不建议运行中手改**
>（会被界面操作覆盖），要改走「设置」菜单或退出后编辑。
密码不想明文落盘用**密钥环认证**（v0.10.9）：`logtail-tui keyring set <服务器名>` 写入系统凭据库后，把该服务器 `auth` 改为 `{ type = "keyring" }`（详见 TUI USAGE §9.1）；GUI 连接对话框与重连自动生效，前端不持有密钥。

## 排障

- **排障日志**：`~/.config/logtail/logtail.log`（泵线程启动/连接/失败/退出都会落盘，与 TUI 共用）
- **闪退/黑屏**：默认只用 DX12/GL 渲染后端（Vulkan 在部分 Windows 驱动上会崩）。仍出问题时可试
  `set WGPU_BACKEND=opengl` 后启动，把结果反馈给维护者。
- **中文乱码/方框**：程序自动加载 `C:\Windows\Fonts\msyh.ttc`（微软雅黑），状态栏会提示是否成功。
- **连接失败**：先跑 TUI 的 `logtail-tui --check-config` 校验 config.toml；SSH 认证/TOFU 问题与 TUI 完全一致；
  具体失败原因看状态栏红字与 logtail.log。
- **docker 源连上就出 permission denied**：状态栏会自动提示——服务器上执行
  `sudo usermod -aG docker <用户名>` 后重新连接（docker 组权限等效 root，账号妥善保管）。
- **模式/远筛/预设真机验证**：命令拼装已由单测锁定；连真实源后建议各过一遍——模式下拉切快捷看回放量变化、「⏮ 更早」翻倍、
  过滤后开远筛看带宽下降、预设一键出「仅ERROR(1h)」。
