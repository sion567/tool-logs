# logtail 使用手册

> 面向使用者的完整操作说明。开发与设计细节见 `../logtail-design.md`；30 秒速览见 [README](README.md)。
> 当前版本：v0.10.3（logtail-tui；核心库 logtail-core，workspace 结构见 ../logtail-design.md）

---

## 1. 这是什么

一个基于 SSH 的终端日志查看器：把远程服务器上 docker / 文件 / systemd 的日志流拉到本地，在本地做实时过滤、着色、下钻、复制、导出——替代 `ssh + docker logs -f + grep` 的手工排障循环。

核心卖点：

- **不用先连服务器再敲命令**：服务器和源配置一次，之后左栏选中回车即连
- **过滤不重跑**：本地 `/` 输入即筛，不重新执行远程命令
- **`P` 一键把过滤推到远端**：`| grep` 在服务器执行，高吞吐源带宽大幅下降
- **多源 tab**：多个源同时保持连接，`,` / `.` 秒切，不拆流

## 2. 安装

### 方式一：源码构建

```bash
git clone <仓库地址> && cd logtail
cargo build --release
# 二进制在 target/release/logtail
./target/release/logtail --version   # logtail v0.7.0
```

### 方式二：直接用已构建的二进制

把 `target/release/logtail(.exe)` 拷到任意有网络的位置即可，单文件、无运行时依赖。

要求：能通过 SSH（密码或私钥）访问目标服务器；目标机上 `docker` / `tail` / `journalctl` 按需可用。

## 3. 首次运行（30 秒上手）

```bash
./logtail            # 首次运行自动生成配置模板并退出提示
vim ~/.config/logtail/config.toml   # 填服务器和源（见下节）
./logtail            # 再启动，Tab 聚焦侧栏 → ↑↓ 选源 → Enter 连接
```

连接成功后日志开始滚动。`q` 退出（任何界面层都可用 `Ctrl+C`）。

配置文件路径：`~/.config/logtail/config.toml`（Windows 下为 `%USERPROFILE%\.config\logtail\config.toml`）。

## 4. 配置文件详解

```toml
[general]
default_tail = 500            # 预留：默认 --tail 行数
max_buffer_lines = 10000      # 本地缓冲上限（淘汰最旧，line_no 不回收）
theme = "dark"                # 预留
remember_last_source = true   # 退出记住激活源与模式，下次启动自动连

[[servers]]                   # SSH 服务器，可多台
name = "prod-01"              # 唯一名，sources 用它引用
host = "192.168.40.198"
port = 22
user = "xxm"
# 认证二选一：
auth = { type = "password", password = "你的密码" }
# auth = { type = "key", path = "~/.ssh/id_rsa", passphrase = "可选" }

[[sources]]                   # 日志源，可多个，挂在某台服务器上
name = "my-api"               # 唯一名 = tab 名 / 导出文件名的一部分
server = "prod-01"
source = { type = "docker", container = "my-app", tail = 500 }

[[sources]]
name = "ffmpeg-log"
server = "prod-01"
source = { type = "file", path = "/var/log/ffmpeg/stream.log", tail = 200 }

[[sources]]
name = "host-system"
server = "prod-01"
source = { type = "journalctl", service = "systemd", since = "today" }

[ui]                          # UI 显示设置（v0.9；热键 w/b/v/h 切换，退出自动记住）
wrap_long_lines = false       # 长行自动换行（true=折行看全文；false=截断+←→ 横滚）
show_sparkline = true         # 日志量时间轴
show_sidebar = true           # 侧栏（隐藏后日志区全宽，b 键切回）
show_hints = true             # 状态栏键位提示

[presets.quick_error]         # 预设：侧栏一键应用的过滤组合
name = "仅ERROR(1h)"
level = "error"               # error / warn / info / debug
since = "1h"                  # docker 直接用；journalctl 自动换算成绝对时间
```

### 六种源类型

| type | 字段 | 远端实际执行的命令 |
|------|------|--------------------|
| `docker` | `container`、`tail`、`follow`、`since`、`until` | `docker logs [-f] --tail N [--since …] [--until …] --timestamps <容器>`（server 级 `sudo = true` 时整体加 sudo 前缀，见 FAQ） |
| `file` | `path`、`tail` | `tail -F -n N <路径>`（精准模式无 `-F`） |
| `journalctl` | `service`、`since` | `journalctl [-f] -u <服务> [--since/--until]`（相对时长自动换算） |
| `command` | `cmd` | 原样执行——**危险**：跳过全部校验，自己保证安全 |
| `loki` (v0.8) | `url`、`query`(LogQL)、`limit` | 远端 `curl` 查 Loki HTTP API（需远端装 curl+jq）；一次性回放，`L`/`f` 换窗口 |
| `local` (v0.8) | `path`、`tail`（**server 省略**） | 本地文件流，不经 SSH；过滤/详情/导出与远端源一致 |

`since`/`until` 接受 `30m`/`1h`/`2d` 相对时长（docker 直接支持、journal 自动换算）或 RFC3339 绝对时间（`2026-11-04T10:00:00+08:00`）。

### 会话记忆

`remember_last_source = true` 时，退出把激活源与模式写入 `~/.config/logtail/state.toml`，下次启动自动连接上次的源。精准模式的时间窗不持久化（次日已过期），恢复为全量。

## 5. 界面导览

```
┌─ 标题栏 ──────────────────────────────────────────────┐
│ 远程日志查看器 v0.7.0  ●[my-api] ●[nginx] ■[sys]      │ ← tab 条：每个已连接源一格
├─ 侧栏 ─┬─ 工具栏 ─────────────────────────────────────┤
│ ▾ 服务器│ 模式:全量 级别:全部 过滤:[无] 正则:关 跟随:● │ ← 当前状态一目了然
│  ● my- │ ▄█▅▂▁ ▃▄▂▁▁ …                                │ ← 日志量时间轴（按秒）
│  ⚡预设 │ ───────────────────────────────────────────  │
│        │ 14:02:01 INFO  start sync                     │
│        │ 14:02:04 ERROR db refused          ← 红字     │ ← 日志区（右侧滚动条）
│        │ ───── 选中行详情 (line_no=1240) ─────          │
│        │ 时间: … 级别: ERROR 源: prod-01/my-app         │ ← 详情面板（回车展开）
├────────┴───────────────────────────────────────────────┤
│ 3 行 3 匹配 | 状态消息 | Tab:侧栏 q:退出 /:过滤 …      │ ← 状态栏
└────────────────────────────────────────────────────────┘
```

- **标题栏 tab 条**：`*[源名]` = 流中（活跃）；非流中直接标注状态：`[源名·已结束]`、`[源名·失败]`、`[源名·连接中]`（v0.8.7 起中文状态词，激活的 tab 蓝底反白）
- **侧栏**：服务器树 + 源列表（`*` 流中 / `已结束` / `失败` / `连接中` 文字标注）+ 预设区
- **工具栏**：模式 / 级别 / 过滤框（编辑中黄字显示光标）/ 正则开关 / 跟随态 / 远筛指示（紫红加粗）
- **sparkline**：每秒日志量柱状迷你图，刷屏时一眼看到峰值
- **状态栏**：行数/匹配数 + 状态消息（失败/超时为红字）+ 快捷键提示

| `Enter` | 展开选中行详情面板 |
| `C` / `c` | 清屏（只清显示，连接不断；新日志继续进缓冲） |

### 日志区 · 过滤

| 键 | 功能 |
|----|------|
| `/` | 开始输入过滤（再按可编辑当前规则） |
| `Enter` | 确认过滤（空输入 = 清空过滤） |
| `Esc` | 清空过滤 |
| `Ctrl+R` | 正则 / 文本模式切换（任何时刻；输入过滤词时**字母照常输入**；大小写上报都接受） |
| `r` | 切换正则（**未在输入过滤词时**；输入中 `r` 是普通字母） |
| `Home` / `End` | 编辑过滤词时跳到开头 / 结尾（v0.7.5） |

| `0` | 级别恢复全部 |

### 日志区 · 连接与模式

| 键 | 功能 |
|----|------|
| `,` / `.` | 切换上一个 / 下一个已连接 tab（不拆流） |
| `f` | 模式循环 全量→快捷(1h)→精准(近1h)：**按两次确认**（会重建会话） |
| `R`（大写） | 重连当前源（先断旧会话）；小写 `r` 是正则切换，注意区分 |
| `L` / `l` | 加载更早：全量→回放 24h；快捷时长翻倍；精准→窗口向过去平移一个窗口宽度 |

| 键 | 功能 |
|----|------|
| `c` | 复制该行原文到系统剪贴板 |
| `t` | 按该行 trace_id 过滤（该行解析出了 trace_id 时） |
| `p` | 聚焦源提示（同屏分屏规划中） |
| `q` / `Esc` | 关闭面板 |
| **其它按键照常** | 面板开着 `↑↓` 换选中行（面板跟随刷新）、`R` 重连、`/` 过滤、`,`/`.` 切 tab 都可用（v0.7.5）；上下文 ±5 全部可见（面板加高，v0.7.6） |

### 工具

| 键 | 功能 |
|----|------|
| `e` | 导出当前源整份会话日志到 `./logtail-<源名>-<时间戳>.log` |

## 7. 核心功能详解

### 7.1 多源 tab

每个连接成功的源自动进入标题栏 tab 条。侧栏再连一个源，旧连接**不断开**、后台继续收流；`,` / `.` 在 tab 间循环切换，切回的 tab 显示它离开之后积累的全部日志。已结束（`■`）或失败（`✗`）的 tab 也能切回去看存量日志，按 `R` 重连。

### 7.2 过滤三层

1. **级别阈值**（`1`-`4`/`0`）：按级别 `>=` 阈值筛，纯本地，即时生效
2. **内容过滤**（`/`）：文本包含或正则（`Ctrl+R` 切换；未输入时按 `r` 也可以），命中行整行保留，命中片段**反白高亮**；正则写错落 Error 态不丢输入，`Esc`/`Enter` 回编辑继续改。过滤词里可以放心输入任意字母——包括 `error` 这种带 r 的词（v0.7.2 修复）
   **多关键词**（v0.10）：文本模式 `timeout|refused` 用 `|` 分隔多个词，**任一命中即匹配、全部反白**；正则模式下 `|` 本就是正则语法
   **过滤应用后其它按键照常可用**：`↑↓` 导航、`R` 重连、`L`/`e`/`P` 都不受影响，过滤持续生效；`Esc` 清空过滤，`/` 重新编辑（v0.7.3 修复——此前过滤一应用其它键就全部失灵）
3. **远程预过滤**（`P`，需先有 1 或 2）：把过滤 pattern 推到远端执行 `| grep -E --line-buffered`，服务器只回传匹配行。适合"日志量巨大但只关心一种错"的场景——本地过滤是事后筛，远筛是**源头减量**。

> `P` 的安全机制：pattern 过专用白名单（正则元字符放行，引号/分号/反引号/`$` 等一律拒绝），拒绝的 pattern 不会拼接进任何命令。工具栏紫红 `远筛:…` 提示远筛在生效，再按 `P` 关闭并自动重连恢复全量。

### 7.3 下钻与取证

`↑↓` 选中可疑行 → `Enter` 展开详情：时间、级别、来源、原始行、**上下文 ±5 行**（选中行标 `▶`）→ `c` 复制原文留证，或 `t` 沿 trace_id 一查到底。

### 7.4 回看历史与导出

- `L` 往回翻：快捷模式时长每次翻倍；精准模式窗口整体向过去平移（比如看了 10:00-11:00，再按 `L` 看 09:00-10:00）
- `e` 导出：把当前源**全部**缓冲（含被本地过滤滤掉的行）写成 `.log`：

```
# logtail 会话导出 源=my-api 行数=1240 时间=2026-11-04T18:00:00+08:00
2026-11-04T09:59:59.123+08:00  INFO  start sync
2026-11-04T10:00:04.987+08:00 ERROR db connection refused
-       INFO  retry #1                ← 无时间戳的行用 - 占位
```

文件落在启动 logtail 的当前目录。

## 8. 典型排障工作流

```
1. ./logtail                          # 启动，自动连上次的源
2. 报警来了 → 侧栏选目标源 Enter       # 没连过就先连
3. 持续刷屏看不清 → Space 暂停跟随     # 或先 / 输入关键字再暂停
4. / 输入 "timeout" 回车              # 即时筛，不用重跑远程命令
5. ↑↓ 选中报错行 → Enter              # 看上下文 ±5，确认前因后果
6. c 复制原文贴进工单
7. 量大带宽疼 → P                     # 把 timeout 过滤推到远端，服务器只回传匹配行
8. 要看更早的 → L 翻倍回放 / 精准模式平移
9. 证据存档 → e 导出 .log
10. 修完部署后 → R 重连观察新日志
```

## 9. 无头模式 `--demo`

不开 TUI、直接把着色日志流打印到终端（管道/脚本里好用）：

```bash
LOGTAIL_HOST=192.168.40.198 LOGTAIL_USER=xxm LOGTAIL_PASS='密码' \
LOGTAIL_CMD="docker logs -f --tail 100 --timestamps my-app" \

./logtail --demo
```

`--version` / `-V` 打印版本。

## 10. 常见问题（FAQ）

**Q：连接成功但一直没数据？**
最常见原因：模式停在**快捷(1h)**——只回放最近 1 小时，安静的服务（如无流量的流媒体/守护进程）期间可能一条日志都没有。状态栏会提示"⚠ 当前只回放最近 1h…"。按 `f` 两次（确认）切**全量**回放全部历史，或按 `L` 前移时间窗。要查配置问题：`logtail --check-config`。

**Q：老是闪退怎么办？**
三步定位（v0.8.3 起有完整退出轨迹）：

1. **确认跑的是最新版**：`logtail --version`（应为 0.8.3+）。旧版（<0.7.1）没有任何日志机制，闪退无痕
2. **看闪退日志**：`~/.config/logtail/logtail.log`——每次启动/退出/panic 都有记录：
   - 有"启动"有"正常退出" = 不是闪退，是被外部关闭（关终端窗口/杀进程/杀软）
   - 有"启动"无"正常退出" = 程序异常退出，下一条就是 PANIC 原因，发出来即可定位
   - 文件根本不存在 = 跑的是旧版二进制，换最新 release
3. **修复后仍闪退**：连同日志内容一起反馈

**Q：界面错乱了（日志画进侧栏、每行碎片化）？**
两种情况分别处理：

1. **窗口拖得太窄**（v0.8.5 修复）：窄窗口下固定布局会溢出绘制（详情面板顶出状态栏、日志区压成单字符碎片）。现在布局全部自适应（侧栏让位、详情面板压缩），且窗口小于 40×12 时全屏红字提示"终端太小，请拉大"。
2. **符号宽度错位**：按 `C`——清屏同时强制全屏重绘。根因（Unicode 歧义宽度符号）v0.8.2 已全部 ASCII 化消除。

**Q：程序闪退/报错，但终端一闪而过没看清？**
所有启动失败和 panic 现在都会无条件写入 `~/.config/logtail/logtail.log`，闪退后打开这个文件就能看到原因。也可以先跑 `logtail --check-config` 校验配置（TOML 语法、源→服务器引用、字段白名单都会检查并给出 ✔/✘ 报告）。

**Q：连接失败，状态栏红字"SSH 连接失败"？**
检查 host/port、网络可达性；服务器 `sshd` 是否限制来源 IP。20 秒无响应按超时处理。

**Q：红字"认证被拒绝 / 认证失败"？**
密码错，或私钥路径不对 / 带 passphrase 没填。`auth = { type = "key", path = "~/.ssh/id_rsa", passphrase = "…" }`，`~` 会自动展开。

**Q：连接成功但立刻结束，日志区显示 `permission denied ... /var/run/docker.sock`？**
出现这种日志时状态栏会**自动红字提示**修复命令（v0.7.6）：
当前 SSH 用户不在服务器的 `docker` 组，无权访问 docker 守护进程。在服务器上执行一次（需要服务器管理员）：

```bash
sudo usermod -aG docker <用户名> && <用户名> 重新 SSH 登录生效
```

注意：`docker` 组权限等效 root（可挂载宿主文件系统进容器），给排障账号添加属常规做法，但账号需妥善保管。验证：`groups | grep docker`。

**Q：journalctl 提示 "You are currently not seeing messages from other users"？**
当前账号不在 `adm`/`systemd-journal` 组，只能看到自己的用户级日志。`sudo usermod -aG systemd-journal <用户>` 后重新登录即可看全量（需要服务器权限）。

**Q：过滤输入中文会乱或崩吗？**
不会。光标按**字符**而非字节计数，中文/emoji 编辑、左右移动、退格都安全（有单测锁定）。

**Q：远端命令结束了怎么办？**
状态栏提示"远程命令已结束（按 R 重连）"，tab 标记 `■`。`docker logs -f` 只有容器重启/停止才会结束；`tail` 单文件持续存在。按 `R` 重连。

**Q：暂停跟随之后新日志去哪了？**
照常进本地缓冲（最多 `max_buffer_lines` 行），`Space` 或 `G` 恢复时都在；切走 tab 再切回来也在。

**Q：`docker logs` 输出里有颜色码/进度条乱码？**
logtail 会自动剥除远端 ANSI 转义序列再显示（真机验证过）；进度条这类单行多帧输出只保留最新内容。

**Q：配置里的密码明文存着安全吗？**
配置文件依赖文件权限保护（建议 `chmod 600`）。当前版本不做系统密钥环集成（设计文档 §16.3 有迁移计划）。`command` 类型源完全跳过校验，仅在完全信任时使用。

**Q：想放大字体/缩放界面？**
TUI 程序无法控制字号——用终端自带的缩放：Windows Terminal `Ctrl+加号/减号` 或 `Ctrl+滚轮`。
程序侧能做的是**显示密度设置**：`b` 隐藏侧栏、`v` 隐藏时间轴、`h` 隐藏键位提示——日志区可以拿到接近全屏的空间（v0.9，退出自动记住）。

**Q：Windows 终端下跑？**
支持。建议 Windows Terminal；Ctrl+C 退出、中文渲染正常。首次构建若很慢属正常（全量依赖编译）。

## 11. 已知限制

| 限制 | 说明 / 绕行 |
|------|-------------|
| 无长期存储 | 只有 `e` 导出的会话快照；关掉后历史靠远端 `--since` 回放（`L`） |
| 远端样式不保留 | ANSI 颜色被剥除，本地按级别统一着色；样式映射留给后续版本 |
| 日志轮转极端情况 | `tail -F` 覆盖多数轮转；极端 rename 场景需 `R` 重连 |
| 分屏同屏 | 多源靠 tab 快速切换；同屏分栏在路线图（v0.5.x） |
| `command` 源 | 完全跳过校验，供高级用户自担风险 |

## 12. 安全须知

1. **凭据**：密码/私钥存本地配置文件，请保证 `~/.config/logtail/` 仅本人可读
2. **主机密钥**（v0.10）：首次连接自动记录服务器指纹到 `~/.config/logtail/known_hosts`（TOFU）；之后每次连接校验，**指纹不一致直接拒绝连接**（疑似中间人），报错指明处理办法。服务器重装/换钥后删除 known_hosts 中对应行即可
3. **注入防护**：容器名/路径/服务名/时间值/过滤 pattern 全部过白名单，拒绝的输入**不会**被拼接进任何远端命令；唯一例外是 `command` 源（设计如此，文档与界面均标注危险）
4. **远程预过滤**：`P` 会在服务器上启动 `grep` 进程，断开时随 channel 关闭自动回收，无孤儿进程
